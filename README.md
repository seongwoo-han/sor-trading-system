
# 멀티마켓 SOR 기반 주문체결 관리 시스템

## 1. 프로젝트 소개
Spring Boot와 MySQL을 활용한 가상 주식 주문체결 시뮬레이터입니다.

복수 거래소의 호가를 비교하고, SOR(Smart Order Routing) 알고리즘을 통해 주문을 적절한 시장으로 배분하는 시스템입니다.

## 2. 개발 환경
- Backend: Java, Spring Boot
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- Build Tool: Maven

## 3. 주요 기능
- 가상 거래소 A/B 호가 관리
- SOR 기반 주문 라우팅
- 매수 및 매도 주문 처리
- 지정가 및 시장가 주문
- 미체결 주문 관리 및 취소
- 자동 모의시장 가격 변동
- 계좌 잔액 및 보유 수량 관리

## 4. 시스템 구조
웹 UI → REST API → Spring Boot → MySQL

## 5. 실행 방법
