주문 안정성 검증

같은 요청의 반복 전송과 잔액을 두고 경합하는 동시 주문을 실제 주문 API로 확인합니다.

테스트용 대기 주문을 만든 뒤 자동 취소합니다. 지정가는 1원이며, A·B 매도호가가 모두 1원보다 높고 기존 대기 주문이 없을 때만 시작합니다. 자동 모의시장은 정지한 뒤 검증합니다. 검증 중에는 다른 탭에서 매매하거나 호가를 변경하지 마세요. 테스트 주문과 취소 기록은 주문내역에 남습니다.

① 같은 주문을 두 번 전송

같은 요청 ID로 1원 · 1주 주문을 두 번 보냅니다. 주문 번호가 같고 예약금이 1원만 증가하는지 확인합니다.

② 두 주문을 동시에 전송

각 주문이 주문 가능 금액의 절반을 넘도록 두 건을 동시에 보냅니다. 한 건만 접수되고 다른 한 건은 잔액 부족으로 거절돼야 합니다.
